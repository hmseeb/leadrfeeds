    5. Layout structure:
       - Full-width page (no app sidebar - docs should be publicly accessible)
       - Fixed header with logo/title and "Download OpenAPI" button linking to /api/openapi.json
       - Two-column layout on desktop: sticky sidebar nav (w-64) + main content (max-w-4xl)
       - Single column on mobile with hamburger menu for sections

    6. Sections content:

       OVERVIEW:
       - Brief intro: "Read-only API for programmatic access to your feed data"
       - Base URL: https://leadrfeeds.com/api/v1
       - Features: cursor pagination, per-key rate limits, JSON responses

       AUTHENTICATION:
       - Step-by-step guide to create API key (Settings > API Keys > Create)
       - Bearer token format explanation
       - Code example showing Authorization header
       - Note about key shown only once

       ENTRIES (GET /entries):
       - Description: paginated feed entries with filtering
       - ParamTable with all parameters:
         - cursor (string, optional): Pagination cursor from previous response
         - limit (integer, optional): Items per page (default 20, max 100)
         - feed_id (string, optional): Filter by feed UUID
         - collection_id (string, optional): Filter by collection UUID
         - category (string, optional): Filter by feed category
         - start_date (string, optional): ISO 8601 date (entries after)
         - end_date (string, optional): ISO 8601 date (entries before)
         - is_read (boolean, optional): Filter by read status
         - is_starred (boolean, optional): Filter by starred status
         - search (string, optional): Full-text search in title/description/content
       - Multi-language code examples (curl, JavaScript, Python)
       - Response example showing Entry object structure

       FEEDS (GET /feeds):
       - Description: list user's subscribed feeds with unread counts
       - No parameters (returns all subscribed feeds)
       - Code examples
       - Response example showing Feed object

       COLLECTIONS (GET /collections):
       - Description: list user's collections with nested feeds
       - No parameters
       - Code examples
       - Response example showing Collection object with feeds array

       STATS (GET /stats):
       - Description: aggregate statistics
       - No parameters
       - Code examples
       - Response example showing total_unread, total_starred, feeds array

       ERRORS:
       - Error response format: { error: { code, message, status } }
       - Table of error codes:
         - 400 BAD_REQUEST: Invalid parameters
         - 401 UNAUTHORIZED: Missing/invalid API key
         - 404 NOT_FOUND: Resource not found
         - 429 RATE_LIMITED: Too many requests
         - 500 INTERNAL_ERROR: Server error
       - Example error response

       RATE LIMITS:
       - 100 requests per minute per API key
       - Headers: X-RateLimit-Remaining, X-RateLimit-Reset
       - 429 response includes Retry-After header
       - Best practices: cache responses, use cursor pagination

    7. Styling:
       - Use existing Tailwind classes (bg-background, text-foreground, etc.)
       - Section headings: text-2xl font-bold mb-4
       - Subsections: text-xl font-semibold mb-3
