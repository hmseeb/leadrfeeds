Create GET /api/v1/feeds endpoint following Phase 5 patterns:

1. **Get userId** from `locals.apiUser!.userId` (guaranteed by auth middleware)

2. **Query user_subscriptions with feed join:**
   ```typescript
   const { data: subscriptions, error } = await supabase
     .from('user_subscriptions')
     .select(`
       feed_id,
       subscribed_at,
       feeds:feed_id (
         id, title, url, site_url, description, category, image
       )
     `)
     .eq('user_id', userId)
     .order('subscribed_at', { ascending: false });
   ```

3. **Handle empty subscriptions** - Return `successResponse([])` (not error)

4. **Call get_unread_counts RPC:**
   ```typescript
   const { data: unreadData, error: unreadError } = await supabase.rpc('get_unread_counts', {
     user_id_param: userId
   });
   ```

5. **Build unread Map for O(1) lookup:**
   ```typescript
   const unreadMap = new Map<string, number>(
     unreadData?.map((u: { feed_id: string; unread_count: number }) =>
       [u.feed_id, u.unread_count]
     ) || []
   );
   ```

6. **Transform to response shape:**
   - Handle Supabase feed relation (may be array or object): `Array.isArray(sub.feeds) ? sub.feeds[0] : sub.feeds`
   - Filter out broken relations: `.filter(sub => sub.feeds)`
   - Include: id, title, url, site_url, description, category, image, unread_count, subscribed_at

7. **Return successResponse** (non-paginated, NOT paginatedResponse)

**Important patterns from Phase 5:**
- Use `getSupabaseAdmin()` for database access
- Use `serverError()` for database errors (never expose details)
- Non-null assertion on `locals.apiUser!` is safe after auth middleware
- Order by subscribed_at DESC for consistent ordering

**Imports needed:**
