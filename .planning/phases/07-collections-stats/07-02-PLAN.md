1. Parse collection_id parameter (add after existing filter parsing around line 35):

2. After getting subscribedFeedIds (around line 69), add collection filter logic:

   ```typescript
   // If collection_id provided, intersect with collection feeds
   if (collectionId) {
     // Verify collection belongs to user (security: prevent accessing other users' collections)
     const { data: collection, error: collError } = await supabase
       .from('feed_collections')
       .select('id')
       .eq('id', collectionId)
       .eq('user_id', userId)
       .single();

     if (collError || !collection) {
       return badRequest('Collection not found', 'COLLECTION_NOT_FOUND');
     }

     // Get feed IDs in this collection
     const { data: collFeeds, error: cfError } = await supabase
       .from('collection_feeds')
       .select('feed_id')
       .eq('collection_id', collectionId);

     if (cfError) {
       console.error('Collection feeds error:', cfError);
       return serverError();
     }

     const collectionFeedIds = collFeeds?.map(cf => cf.feed_id) || [];

     // Empty collection = empty result
     if (collectionFeedIds.length === 0) {
       return paginatedResponse([], { next_cursor: null, has_more: false, limit });
     }

     // Intersect collection feeds with subscribed feeds
     // (user may have unsubscribed from a feed that's still in collection)
     const collectionSet = new Set(collectionFeedIds);
     subscribedFeedIds = subscribedFeedIds.filter(id => collectionSet.has(id));

     // If no overlap between collection and subscriptions, empty result
     if (subscribedFeedIds.length === 0) {
       return paginatedResponse([], { next_cursor: null, has_more: false, limit });
     }
   }
   ```

3. Important: This must be added AFTER the "Return empty result if no subscriptions" check (line 72-74) but BEFORE the feed_id validation (line 77).

4. The rest of the endpoint remains unchanged - the subscribedFeedIds array is already used to filter the entries query.

5. Note: collection_id can be combined with feed_id filter. If feed_id is not in the collection, the existing feed_id validation will catch it (feed not in subscribedFeedIds after intersection).

Key security consideration: Always verify collection ownership via feed_collections.user_id = userId before using the collection_id.
