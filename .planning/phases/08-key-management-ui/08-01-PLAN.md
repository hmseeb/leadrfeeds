<task type="auto">
  <name>Task 1: Create server endpoint for API key CRUD</name>
  <files>app/src/routes/settings/api-keys/+server.ts</files>
  <action>
Create SvelteKit server endpoint with three handlers:

**Authentication approach**: Since the app uses client-side Supabase auth (no server-side sessions), the endpoint must receive the access token from the client in the Authorization header (Bearer token). Use `getSupabaseAdmin().auth.getUser(token)` to validate and get user.

**POST handler** (create key):
1. Extract Bearer token from Authorization header
2. Validate user via `getSupabaseAdmin().auth.getUser(token)`
3. Parse JSON body for `label` (required string) and `expires_at` (optional ISO date string)
4. Validate label is non-empty string (max 100 chars)
5. If `expires_at` provided, validate it's a future date
6. Generate key using `generateApiKey()` from `$lib/server/api-keys`
7. Hash using `sha256()` from `$lib/server/api-keys`
8. Insert into api_keys table: `user_id`, `label`, `key_prefix`, `key_hash`, `expires_at`
9. Return JSON with `id`, `label`, `key_prefix`, `expires_at`, `created_at`, AND `full_key` (only time it's returned)

**GET handler** (list keys):
1. Extract and validate Bearer token (same as POST)
2. Query api_keys where user_id matches
3. Select: `id`, `label`, `key_prefix`, `expires_at`, `revoked_at`, `last_used_at`, `created_at`
4. Order by `created_at DESC`
5. Return JSON array of keys (never include key_hash or full key)

**DELETE handler** (revoke key):
1. Extract and validate Bearer token (same as POST)
2. Parse JSON body for `id` (required UUID)
3. Update api_keys set `revoked_at = now()` where `id` matches AND `user_id` matches (security: users can only revoke their own keys)
4. If no rows updated, return 404
5. Return 200 with `{ success: true }`

**Error handling**:
- 401 for missing/invalid token
- 400 for invalid request body
- 404 for key not found (DELETE)
- 500 for database errors

Import from `@sveltejs/kit`: `json`, `error`
Import from `$lib/server/supabase`: `getSupabaseAdmin`
Import from `$lib/server/api-keys`: `generateApiKey`, `sha256`
