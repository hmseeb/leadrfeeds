<task type="auto">
  <name>Task 2: Create pagination utilities</name>
  <files>app/src/lib/server/pagination.ts</files>
  <action>
Create `app/src/lib/server/pagination.ts` with:

1. **Constants** (private):
   - `DEFAULT_LIMIT = 50`
   - `MAX_LIMIT = 100`

2. **EntryCursorData interface** (export) - Data encoded in cursor:
   ```typescript
   export interface EntryCursorData {
     p: string;  // published_at ISO string
     i: string;  // id
   }
   ```
   Use short keys (p, i) to minimize cursor size since cursors are opaque.

3. **encodeCursor(data: EntryCursorData): string** (export):
   - Return `btoa(JSON.stringify(data))`

4. **decodeCursor(cursor: string): EntryCursorData | null** (export):
   - Try/catch: `atob(cursor)` then `JSON.parse`
   - Validate structure: `parsed.p` and `parsed.i` must be strings
   - Validate date: `new Date(parsed.p)` must be valid (not NaN)
   - Return null on any validation failure

5. **getEffectiveLimit(requested?: number): number** (export):
   - If undefined, null, or < 1, return DEFAULT_LIMIT
   - Otherwise return `Math.min(requested, MAX_LIMIT)`

6. **PaginationMeta interface** (export):
   ```typescript
   export interface PaginationMeta {
     next_cursor: string | null;
     has_more: boolean;
     limit: number;
   }
   ```

7. **buildPaginationMeta<T>(results: T[], limit: number, extractCursor: (item: T) => EntryCursorData)** (export):
   - `hasMore = results.length > limit`
   - `items = hasMore ? results.slice(0, limit) : results`
   - `nextCursor = hasMore && items.length > 0 ? encodeCursor(extractCursor(items[items.length - 1])) : null`
   - Return `{ items, meta: { next_cursor, has_more, limit } }`

8. **parsePaginationParams(url: URL): { cursor: string | null; limit: number }** (export):
   - Get 'cursor' from searchParams (can be null)
   - Get 'limit' from searchParams, parse to int, pass through getEffectiveLimit
   - Return both

Reference 03-RESEARCH.md "Complete pagination.ts" section for exact implementation.
